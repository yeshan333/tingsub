# 隐私与权限

## 数据流

TingSub 只把你主动开启的标签页音频发送到同一台机器的 `127.0.0.1:18765`，识别和翻译在本机 Python 进程执行。当前实现没有云 API、遥测、账号系统或云端回退。安装依赖和 `prepare` 会访问包仓库／Hugging Face；视频网站自身流量不属于 TingSub 控制范围。

正常字幕会话的音频片段与文本保存在内存中，不自动写入录音或转写文件。浮层最多展示最近两个片段并清理过期文本，但这不构成安全擦除内存的保证。操作系统、浏览器、视频网站和其他软件有各自的行为。

开发用性能脚本会主动把合成音频、转写、计时及截图保存到已忽略的 `.local/`，并向终端输出推理结果。共享诊断信息前请检查这些文件。常规服务访问日志已关闭，但错误消息仍可能包含本地细节。

## 浏览器权限

| 权限 | 原因 |
| --- | --- |
| `activeTab` | 用户点击工具栏后访问所选页面 |
| `tabCapture` | 采集选定标签页音频，不采集麦克风 |
| `offscreen` | 弹窗关闭后继续处理音频 |
| `scripting` | 在选定页面插入字幕浮层 |
| `storage` | 本地保存设置和配对码，不通过浏览器同步 |
| `http://127.0.0.1/*` | 访问本机服务；Chrome 主机权限按主机限定，连接代码与 CSP 指向 18765 端口 |

不申请全部网站主机权限或麦克风权限，页面导航会停止采集。字幕存在页面 DOM 中，使用开放的 shadow root，当前网站可读取显示文字。因此不能把网页内字幕视为对该网站保密。配对码保存在扩展存储中，不注入页面 DOM。

## 本地密钥

数据目录中的 `token` 创建时仅允许文件所有者读写，扩展用它完成 WebSocket 认证，请像密码一样保护。扩展来源检查只是额外的浏览器边界，不能替代配对码。同一系统账户下运行的其他软件不在这条防护边界内。

独立应用轮换配对码：退出 TingSub 并停止字幕，在 Finder「前往文件夹」打开 `~/Library/Application Support/TingSub`，只删除 `token`，重新打开应用并复制新码，在插件中替换。源码用户则在停止服务后删除 `.local/token`，运行 `uv run --frozen tingsub pair` 生成新码。无需为了轮换密钥删除整个数据目录。卸载见[安装指南](installation.md)，漏洞报告见[安全政策](../../SECURITY.zh-CN.md)。

## 桌面本地数据

桌面界面不额外上传音频或遥测。独立应用数据目录为 `~/Library/Application Support/TingSub`，源码运行默认是 `.local`。目录内 `preferences.json` 保存字幕参数，`interface.json` 保存界面外观，`desktop.log` 保存子进程输出，每次启动／准备覆盖；不主动记录录音或转录，但错误可能含本地路径。配对码只有点击复制时进入系统剪贴板，页面和日志不会主动显示它。安装桌面依赖需要访问包仓库；只有主动准备模型或点击文档链接才有相应网络访问。
